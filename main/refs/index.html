    minevent.BaseCondition ¶

    Bases: ABC

    Define the base class to implement a condition for EventHandler.

    A child class has to implement the following methods:

    - ``evaluate``
- ``equal``

    equal is the primary comparison API and == delegates to it. Conditions are intentionally unhashable, like the event handlers.

    Example 
    >>> from minevent import PeriodicCondition
>>> condition = PeriodicCondition(freq=3)
>>> condition.evaluate()
True
>>> condition.evaluate()
False
>>> condition.evaluate()
False
>>> condition.evaluate()
True
>>> condition.evaluate()
False
>>> condition.evaluate()
False
>>> condition.evaluate()
True

    minevent.BaseEventHandler ¶

    Bases: ABC

    Define the base class to implement an event handler.

    A child class has to implement the following methods:

    - ``handle``
- ``equal``

    equal is the primary comparison API and == delegates to it. Because equality is defined by equal (for example with coola.objects_are_equal, which supports arrays and tensors), no consistent hash can be computed, so event handlers are intentionally unhashable: they cannot be put in a set or used as dict keys. Use the Subscription returned by EventManager.add_event_handler to identify a registration.

    Example 
    >>> from minevent import EventHandler
>>> def hello_handler() -> None:
...     print("Hello!")
...
>>> handler = EventHandler(hello_handler)
>>> handler
EventHandler(
  (handler): <function hello_handler at 0x...>
  (handler_args): ()
  (handler_kwargs): {}
)
>>> handler.handle()
Hello!

    minevent.EventHandler ¶

    Bases: BaseEventHandler

    Implement an event handler.

    This class wraps a callable function or method and allows it to be executed as an event handler. The handler can be configured with positional and keyword arguments that will be passed when the handler is executed, and with an optional condition. When a condition is given, the handler is executed only if the condition evaluates to True. This is useful for scenarios where event handlers should only run under specific circumstances, such as periodic execution or state-based triggering.

    The handler is called as handler(*handler_args, **handler_kwargs, **payload), where payload is the data given when the event is triggered. Two event handlers are equal if they have the same class, handler, arguments and condition.

    Equality compares the handlers with coola.objects_are_equal, which falls back to == for functions. Module-level functions compare equal to themselves, but lambdas and bound methods of different instances (obj.method != other.method) do not, so has_event_handler and remove_event_handler do not find a handler built from a new lambda or from another instance. Keep a reference to the function, or use the Subscription returned by EventManager.add_event_handler, which does not need equality. Arrays and tensors in handler_args are compared by value.

    Parameters:

    Name Type Description Default
    handler Callable

    The callable function or method to be invoked when the event is triggered (and the condition is True).

    		 required
    handler_args Sequence[Any] | None

    The positional arguments to pass to the handler when it is called. Default is None.

    		 None
    handler_kwargs dict[str, Any] | None

    The keyword arguments to pass to the handler when it is called. The dictionary is copied, so changing it afterwards does not change the handler. Default is None.

    		 None
    condition BaseCondition | Callable[[], bool] | None

    The condition object that controls whether the handler is executed. The condition's evaluate method is called without arguments, each time the event is triggered, and must return a boolean value. A function without argument that returns a boolean is also accepted; it is wrapped in a CallableCondition. If None, the handler is always executed. Default is None.

    		 None

    Raises:

    Type Description
    TypeError

    if handler is not callable, or if condition is neither None, a BaseCondition nor callable.
    Example 
    >>> from minevent import EventHandler, PeriodicCondition
>>> def hello_handler() -> None:
...     print("Hello!")
...
>>> handler = EventHandler(hello_handler)
>>> handler

  (handler): <function hello_handler at 0x...>
  (handler_args): ()
  (handler_kwargs): {}
)
>>> handler.handle()
Hello!
>>> handler = EventHandler(print, handler_args=["Hello!"])
>>> handler.handle()
Hello!
>>> handler = EventHandler(hello_handler, condition=PeriodicCondition(freq=3))
>>> handler
EventHandler(
  (handler): <function hello_handler at 0x...>
  (handler_args): ()
  (handler_kwargs): {}
  (condition): PeriodicCondition(freq=3, skip_first=False, step=0)
)
>>> handler.handle()
Hello!
>>> handler.handle()
>>> handler.handle()
>>> handler.handle()
Hello!

    minevent.EventManager ¶

    Implement an event manager.

    This event manager allows registering event handlers and triggering events. An event is represented by a case-sensitive string. Each event can have multiple handlers attached, and all handlers are executed in the order they were added when the event is triggered. The manager also tracks the last triggered event.

    Error policy: handlers run fail-fast. If a handler raises, the exception propagates to the caller of trigger_event and the remaining handlers of that event are not executed.

    Thread safety: the registration, removal and inspection of handlers are protected by a reentrant lock, and trigger_event runs the handlers on a snapshot taken under the lock, outside of it. So handlers can be registered in one thread and events triggered from worker threads. The handlers themselves run in the thread that triggers the event, concurrently if several threads trigger the same event, so a handler that shares state must be thread-safe. The mutable state of a condition, such as the counter of PeriodicCondition, is not protected.

    Example 
    >>> from minevent import EventHandler, EventManager
>>> def hello_handler():
...     print("Hello!")
...
>>> manager = EventManager()
>>> _ = manager.add_event_handler("my_event", EventHandler(hello_handler))
>>> manager.trigger_event("my_event")
Hello!

    minevent.EventManager.reset ¶

    reset() -> None

    Reset the event manager.

    This method removes all registered event handlers from the event manager and resets the last triggered event to None. After calling this method, the event manager returns to its initial state.

    Example 
    >>> # Create an event manager
>>> from minevent import EventManager
>>> manager = EventManager()

...     print("Hello!")

    minevent.EventManager.trigger_event ¶

    trigger_event(event: str, **payload: Any) -> None

    Trigger the handler(s) for the given event.

    This method executes all event handlers registered for the specified event in the order they were added. The last triggered event name is updated regardless of whether any handlers are registered.

    Handlers are executed fail-fast: if a handler raises, the exception propagates and the remaining handlers are skipped.

    The handlers are read from a snapshot taken when the event is triggered. Handlers added or removed by a running handler take effect on the next trigger, not the current one.

    The keyword arguments payload are passed to every handler as keyword arguments, after the arguments given at registration. Without payload, handlers are called exactly as before. A handler that does not accept the payload raises a TypeError.

    Parameters:

    Name Type Description Default
    event str

    The event name (case-sensitive string) to trigger.

    		 required
    **payload Any

    The data passed to the handlers as keyword arguments.

    		 {}

    Raises:

    Type Description
    TypeError

    if event is not a string.
    Example 
    >>> from minevent import EventHandler, EventManager
>>> manager = EventManager()
>>> manager.trigger_event("my_event")  # do nothing because there is no event handler
>>> def hello_handler():
...     print("Hello!")
...
>>> _ = manager.add_event_handler("my_event", EventHandler(hello_handler))
>>> manager.trigger_event("my_event")
Hello!
>>> def epoch_handler(epoch):
...     print(f"epoch {epoch}")
...
>>> _ = manager.add_event_handler("epoch_end", EventHandler(epoch_handler))
>>> manager.trigger_event("epoch_end", epoch=3)

    minevent.PeriodicCondition ¶

    Bases: BaseCondition

    Implement a periodic condition.

    This condition evaluates to True on the first call and then every freq calls to the evaluate method. It maintains an internal counter that increments with each evaluation. The condition is True when the counter modulo freq equals zero.

    Note that evaluate is not idempotent: each call advances the counter, so the condition is stateful. Do not share one instance between several handlers, because they would advance the same counter. Use reset to restart the counter. Two conditions are equal if they have the same freq and skip_first; the current progress is ignored, so duplicate handlers are detected whatever their progress.

    Parameters:

    Name Type Description Default
    freq int

    The frequency (interval) at which the condition evaluates to True. Must be a positive integer.

    		 required
    skip_first bool

    If True, the first call evaluates to False, and then the condition evaluates to True every freq calls. Default is False.

    		 False

    Raises:

    Type Description
    TypeError

    if freq is not an integer.
    ValueError

    if freq is lower than 1.
    Example 
    >>> from minevent import PeriodicCondition
>>> condition = PeriodicCondition(freq=3)
>>> condition.evaluate()
True
>>> condition.evaluate()
False
>>> condition.evaluate()
False
>>> condition.evaluate()
True
>>> condition.evaluate()
False
>>> condition.evaluate()
False
>>> condition.evaluate()
True
>>> condition = PeriodicCondition(freq=2, skip_first=True)
>>> condition.evaluate()
False
>>> condition.evaluate()
False
>>> condition.evaluate()
True

    minevent.Subscription ¶

    Represent the registration of an event handler to an event.

    A subscription is returned by EventManager.add_event_handler. It removes exactly the registration that created it, so the handler does not need to be re-created to be unsubscribed, and other equal handlers are not removed.

    Parameters:

    Name Type Description Default
    event str

    The event name of the registration.

    		 required
    event_handler BaseEventHandler

    The registered event handler.

    		 required
    remove_func Callable[[str, BaseEventHandler], bool]

    The function that removes the registration. It takes the event name and the event handler, and returns True if the registration was removed, False if it was already removed.

    		 required
    Example 
    >>> from minevent import EventHandler, EventManager
>>> manager = EventManager()
>>> subscription = manager.add_event_handler("my_event", EventHandler(print))
>>> subscription.event
'my_event'
>>> subscription.remove()
True
>>> subscription.remove()
False
>>> manager.events
[]
