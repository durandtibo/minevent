    minevent.handlers ¶

    Implement the event handlers.

    minevent.handlers.BaseEventHandler ¶

    Bases: ABC

    Define the base class to implement an event handler.

    A child class has to implement the following methods:

    - ``handle``
- ``equal``

    equal is the primary comparison API and == delegates to it. Because equality is defined by equal (for example with coola.objects_are_equal, which supports arrays and tensors), no consistent hash can be computed, so event handlers are intentionally unhashable: they cannot be put in a set or used as dict keys. Use the Subscription returned by EventManager.add_event_handler to identify a registration.

    Example 
    >>> from minevent import EventHandler
>>> def hello_handler() -> None:
...     print("Hello!")
...
>>> handler = EventHandler(hello_handler)
>>> handler
EventHandler(
  (handler): <function hello_handler at 0x...>
  (handler_args): ()
  (handler_kwargs): {}
)
>>> handler.handle()
Hello!

    minevent.handlers.BaseEventHandler.equal abstractmethod ¶

    equal(other: object) -> bool

    Compare two event handlers for equality.

    This method should be implemented by child classes to define how event handlers are compared. This is used by the event manager to check for duplicate handlers.

    Parameters:

    Name Type Description Default
    other object

    The other object to compare with. Can be any type, though typically an event handler.

    		 required

    Returns:

    Type Description
    bool

    True if the two event handlers are considered equal, otherwise False.
    Example 
    >>> from minevent import EventHandler
>>> def hello_handler() -> None:
...     print("Hello!")
...
>>> handler = EventHandler(hello_handler)
>>> handler.equal(EventHandler(hello_handler))
True
>>> handler.equal(EventHandler(print, handler_args=["Hello!"]))
False

    minevent.handlers.EventHandler ¶

    Bases: BaseEventHandler

    Implement an event handler.

    This class wraps a callable function or method and allows it to be executed as an event handler. The handler can be configured with positional and keyword arguments that will be passed when the handler is executed, and with an optional condition. When a condition is given, the handler is executed only if the condition evaluates to True. This is useful for scenarios where event handlers should only run under specific circumstances, such as periodic execution or state-based triggering.

    The handler is called as handler(*handler_args, **handler_kwargs, **payload), where payload is the data given when the event is triggered. Two event handlers are equal if they have the same class, handler, arguments and condition.

    Equality compares the handlers with coola.objects_are_equal, which falls back to == for functions. Module-level functions compare equal to themselves, but lambdas and bound methods of different instances (obj.method != other.method) do not, so has_event_handler and remove_event_handler do not find a handler built from a new lambda or from another instance. Keep a reference to the function, or use the Subscription returned by EventManager.add_event_handler, which does not need equality. Arrays and tensors in handler_args are compared by value.

    Parameters:

    Name Type Description Default
    handler Callable[..., object]

    The callable function or method to be invoked when the event is triggered (and the condition is True).

    		 required
    handler_args Sequence[Any] | None

    The positional arguments to pass to the handler when it is called. Default is None.

    		 None
    handler_kwargs Mapping[str, Any] | None

    The keyword arguments to pass to the handler when it is called. The dictionary is copied, so changing it afterwards does not change the handler. Default is None.

    		 None
    condition BaseCondition | Callable[[], bool] | None

    The condition object that controls whether the handler is executed. The condition's evaluate method is called without arguments, each time the event is triggered, and must return a boolean value. A function without argument that returns a boolean is also accepted; it is wrapped in a CallableCondition. If None, the handler is always executed. Default is None.

    		 None

    Raises:

    Type Description
    TypeError

    if handler is not callable, if handler_args is a str or bytes (which would be split into characters), or if condition is neither None, a BaseCondition nor callable.
    Example 
    >>> from minevent import EventHandler, PeriodicCondition
>>> def hello_handler() -> None:
...     print("Hello!")
...
>>> handler = EventHandler(hello_handler)
>>> handler
EventHandler(
  (handler): <function hello_handler at 0x...>
  (handler_args): ()
  (handler_kwargs): {}
)
>>> handler.handle()
Hello!
>>> handler = EventHandler(print, handler_args=["Hello!"])
>>> handler.handle()
Hello!
>>> handler = EventHandler(hello_handler, condition=PeriodicCondition(freq=3))
>>> handler
EventHandler(
  (handler): <function hello_handler at 0x...>
  (handler_args): ()
  (handler_kwargs): {}
  (condition): PeriodicCondition(freq=3, skip_first=False, step=0)
)
>>> handler.handle()
Hello!
>>> handler.handle()
>>> handler.handle()
>>> handler.handle()
Hello!

    minevent.handlers.EventHandler.ahandle async ¶

    ahandle(**payload: Any) -> None

    Handle the event asynchronously.

    Like handle, but if the handler returns an awaitable (for example because it is a coroutine function), the awaitable is awaited. handle does not await it, so use ahandle (or EventManager.atrigger_event) with coroutine functions.

    Parameters:

    Name Type Description Default
    **payload Any

    The keyword arguments given to EventManager.atrigger_event.

    		 {}
    Example 
    >>> import asyncio
>>> from minevent import EventHandler
>>> async def hello_handler() -> None:
...     print("Hello!")
...
>>> asyncio.run(EventHandler(hello_handler).ahandle())
Hello!
