    Calls¶

    How the handlers and the conditions are called. minevent exports Handler only: the functions of this module are used by the event manager, and adapt_call states the calling rule.

    minevent.calls ¶

    Implement how the code of a user is called.

    Handler is the type of a handler. adapt_call turns a handler or a condition into a callable of the context, describe names it, reject_awaitable rejects the awaitable result of a synchronous call, and add_error_note completes the exception that it raises. These helpers are used by minevent.manager, and minevent exports Handler only.

    minevent.calls.Handler module-attribute ¶

    Handler = Callable[[], object] | Callable[[Context], object]

    A handler: a function without parameter or with the Context of the trigger.

    minevent.calls.adapt_call ¶

    adapt_call(
    func: Callable[..., object], name: str
) -> Callable[[Context], object]

    Turn a handler or a condition into a callable of the context.

    A callable is called as func() or func(context). A parameter that has a default keeps it: the manager never fills it. The callable is called as func() if no other parameter is left, and as func(context) if exactly one is left and it is positional. Names and annotations are not checked. Any other signature is rejected, including *args and **kwargs (they do not say whether the context is expected), and so is a callable whose signature cannot be inspected. A generator function or an async generator function is rejected too, because calling it runs none of its code. The signature is the one that inspect.signature reports: it does not contain the positional arguments that a functools.partial binds, and it is the one of the wrapped function for a decorator that uses functools.wraps. The annotations do not have to be resolvable: on Python 3.14+, a name that is only imported under TYPE_CHECKING is kept as a forward reference instead of raising a NameError.

    Parameters:

    Name Type Description Default
    func Callable[..., object]

    The callable to inspect.

    		 required
    name str

    The name of the argument that receives func, used in the error messages.

    		 required

    Returns:

    Type Description
    Callable[[Context], object]

    func itself if it is called as func(context), and otherwise a function of the context that calls func(). The signature is read once, by this function: calling the result does not read it again.

    Raises:

    Type Description
    TypeError

    if func is a generator function, if its signature cannot be inspected, or if it needs another argument than the context.
    Example 
    >>> from minevent import Context
>>> from minevent.calls import adapt_call
>>> def read_epoch(context):
...     return context["epoch"]
...
>>> adapt_call(read_epoch, "handler") is read_epoch
True
>>> def train(mode=True):
...     return mode
...
>>> adapt_call(train, "handler")(Context({"epoch": 3}))
True

    minevent.calls.add_error_note ¶

    add_error_note(
    exc: Exception, source: str, event: str
) -> None

    Add a note to the exception raised while handling an event.

    The note says what raised and while handling which event. It is not added if the exception already has it, so an exception instance that is raised again (or a handler that triggers its own event) has one note per distinct note. Adding the note never replaces the exception: if the note cannot be added, for example to a frozen=True dataclass exception, the exception is left without it.

    Parameters:

    Name Type Description Default
    exc Exception

    The exception raised by a handler or a condition.

    		 required
    source str

    What raised the exception, for example the name of the handler (see describe).

    		 required
    event str

    The event that was triggered.

    		 required
    Example 
    >>> from minevent.calls import add_error_note
>>> error = ValueError("boom")
>>> add_error_note(error, "log_epoch", "epoch_end")
>>> error.__notes__
["raised by log_epoch while handling the event 'epoch_end'"]

    minevent.calls.describe ¶

    describe(func: object) -> str

    Name a handler or a condition without calling the repr of its data.

    The repr of a callable can contain its arguments, which can be large or raise, so it is not used in the messages of the package. Naming never raises an Exception, so it cannot replace the error that the name is used to report.

    Parameters:

    Name Type Description Default
    func object

    The object to name, usually a handler or a condition.

    		 required

    Returns:

    Type Description
    str

    The qualified name of the function under a functools.partial (nested partials are unwrapped), or the qualified name of the class of the object if it has no name (for example a callable object), if its name is not a str, or if reading its name raises.
    Example 
    >>> import functools
>>> from minevent.calls import describe
>>> describe(print)
'print'
>>> describe(functools.partial(print, "Hello!"))
'print'

    minevent.calls.reject_awaitable ¶

    reject_awaitable(result: object, message: str) -> None

    Reject the value returned by a function that must be synchronous.

    A coroutine is closed, so it does not emit a RuntimeWarning because it was never awaited. Another awaitable, such as a future, is not modified.

    Parameters:

    Name Type Description Default
    result object

    The value returned by a handler or a condition.

    		 required
    message str

    The message of the error. It names the function that returned result.

    		 required

    Raises:

    Type Description
    TypeError

    if result is an awaitable.
    Example 
    >>> from minevent.calls import reject_awaitable
>>> reject_awaitable(True, "the function returned an awaitable")
